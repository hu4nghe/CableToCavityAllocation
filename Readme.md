# CableToCavityAllocation 

## Overview
The **CableToCavityAllocation** project is prototype to CATIA CableToConnectorAllocation command.

This project is built using GCC 14.2 with CMake as the build system and integrates Python3 for cavity scan and visualization.

---

## Project Structure

### Key Directories and Files
- **`apps/allocator_main/`**: Contains the main application source code.
- **`modules/`**: Includes various modules such as:
  - `electronic_component/`
  - `electronic_container/`
  - `cable_allocator/`
  - `geometry_tools/`
- **`bin/`**: Contains the compiled binaries and data files (`cable_data.csv`).
- **`build/`**: Build directory generated by CMake.
- **`Python/`**: Contains Python scripts for visualization and additional functionality.
- **`.vscode/`**: Configuration files for Visual Studio Code.
- **`CMakeLists.txt`**: Top-level CMake configuration file.


---

## Prerequisites

### System Requirements

- **C++ Compiler**: GCC 14.2 or higher.
- **Python**: Version 3.12 or higher.
- **CMake**: Version 3.16 or higher.

### Dependencies
- **Python Libraries**:
  - `pybind11`
  - `numpy`
  - `opencv-python`

## Setup 



### 1. Set Up Python Environment
```bash
# If a virtual environment is not already set up, the project will attempt to use the default virtual environment located at Python/DSLyon.
# If the virtual environment does not exist, you can create one:
python3 -m venv Python/DSLyon

# For bash
source Python/DSLyon/bin/activate 

# For Windows PowerShell
Python\DSLyon\Scripts\Activate.ps1 
```
```bash
# Install Python Dependencies
pip install -r Python/requirements.txt
```

### 2. Build the Project
```bash
# Create a Build Directory
mkdir build
cd build

# Run CMake
cmake ..

# Compile the Project in Linux
make
```

### 3. Run the Application
```bash
cd ../bin
./allocator_main
```

## Additional Notes

### Python 
The project uses Python for scan cavity's coordinate and visualization. Ensure that the Python scripts in the `Python/` directory are accessible and that the Python environment is correctly configured.

### Connector photos
The connector photos are in the `Ressources/Connectors`. You may copy the path of connector's photo to executable to start a scan. The mask in python script is for dark color cavities. You may need to change the color mask if the cavity is white.


---

## Troubleshooting

### Common Issues

- **Python Errors**:
  - Ensure the virtual environment is activated.
  - Check that all Python dependencies are installed.

- **Build Errors**:
  - Ensure the C++ compiler supports C++23.
  - Clear the `build/` directory and retry:
    ```bash
    rm -rf build
    mkdir build
    cd build
    cmake ..
    make
    ```
